# QA v5

## Estándar
Smoke, invariantes de estado, 650 preguntas, Fisher-Yates, selección, combate, Bestia, timeout, evidencia, historial, rematch y revisión de versiones.

## Auditoría de riesgos
1. P2P real depende de la señalización PeerJS y de las condiciones de NAT/firewall.
2. La base médica es material educativo, no consejo clínico. Las fuentes deben revisarse de forma periódica.
3. Las preguntas heredadas del banco de 150 se conservan por compatibilidad; no se deben interpretar como revisión médica exhaustiva solo porque la lógica de respuestas esté validada.
4. La estética está implementada con arte original/procedural y no incorpora assets copiados de Bloody Roar u otros juegos comerciales.
